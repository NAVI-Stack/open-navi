## What was done

Implemented Context Intake Pipeline Phase 2 (CIP §6 stages 3–5, §8, §13): the
downstream processing that turns raw, provenance-stamped `IntakeRecord`s landed

### New files

- `internal/intake/canonicalize/canonicalize.go` — **stage 3 (Canonicalize)**.
  `Canonicalize(IntakeRecord) (Document, error)`. Renders `text/html`,
  `application/json`, and plain-text/`text/*` payloads to clean Markdown.
  Strips boilerplate (script/style/head/nav/footer/header/aside/form/etc.),
  quoted replies (`>` blocks + "On … wrote:" attributions), and email/IM
  signatures (`-- ` delimiter). Stdlib-only HTML tag-stripper (RE2 has no
  backreferences, so each drop-tag has its own compiled pattern). Pure +
  deterministic.
- `internal/intake/canonicalize/url.go` — `NormalizeURL` (lowercase scheme/host,
  drop fragment, strip tracking params utm_*/gclid/fbclid/…, drop default
  ports, sort query) and `normalizeURLsInText` (rewrites URLs embedded in free
  text, preserving trailing sentence punctuation). Exported for reuse by
  distill.
- `internal/intake/chunk/chunk.go` — **stage 4 (Chunk)**. `Split(text,
  namespace, Options) []Chunk`. Token-bounded (default 3000 tokens, ≈4 chars/
  token), configurable overlap (default 200), paragraph-boundary preferred,
  oversized paragraphs hard-split. Stable chunk IDs = `sha256(namespace, index,
  content)[:32]` — deterministic for identical input bytes. `EstimateTokens`
  exported.
- `internal/intake/distill/distill.go` — **stage 5 (Distill)**, the reusable
  dual-use primitive. `Distill(ctx, Input) Result`. Ingest-side via
  `FromChunks(chunks, opts)`; retrieval-side by constructing `Input` directly
  with `Options.Budget`. Extractive-only V1: near-duplicate collapse (Jaccard
  over 3-gram word shingles, threshold 0.85), budget truncation. Abstractive
  `Summarizer` is interface-only; `NoopSummarizer` is a pass-through; the worker
  passes nil so **no LLM is wired**. Provenance preserved: each survivor carries
  `SourceChunkIDs` (self + collapsed siblings) and `CollapsedIDs`.
- `internal/intake/distill/extract.go` — quote extraction (Markdown
  blockquotes + double-quoted spans, with offsets) and deterministic
  entity-span extraction (url/email/handle/hashtag/identifier/proper_noun via
  capitalization + regex heuristics, no LLM). Higher-priority kinds suppress
  overlapping lower-priority matches via an occupancy bitmap. URLs emitted in
  normalized form.
- `internal/intake/pipeline.go` — `RunStages(ctx, db, rec, cfg, log)` chains
  Canonicalize → Chunk → Distill → persist, maps `distill.DistilledChunk` →
  `schema.IntakeChunk`, and emits per-pass metrics (chunks produced, persisted,
  duplicates, dedupe rate, input/output bytes, quotes, entities) at slog level.
- `internal/store/intake_chunks.go` — raw-SQL store: `SaveIntakeChunk`
  (idempotent `INSERT OR IGNORE`, returns whether a new row landed),
  `GetIntakeChunk`, `ListIntakeChunksByRecord`, `CountIntakeChunksByRecord`.
- Tests: `canonicalize_test.go`, `chunk_test.go`, `distill_test.go`,

### Design decisions

- **Types in `internal/schema`** (not `internal/intake`): mirrors P1's
  cycle-breaking choice so `internal/store` can persist `IntakeChunk` without
  importing `internal/intake`.
- **Stable chunk IDs namespaced by `connectorID\x00sourceID`** (not the record
  UUID) so ids stay stable even if a record is re-admitted under a new UUID; the
  FK still points at the actual stored `intake_records.id`.
- **Resumability via idempotent persistence**: `INSERT OR IGNORE` on a stable PK
  + `UNIQUE(record, index)` makes re-processing a no-op. `resumeDownstream`
  guards with `CountIntakeChunksByRecord` to avoid redundant work on every
  duplicate while still recovering a crashed pass.
- **Distill dual-use signature designed for P4**: ingest passes a chunk batch
  with no budget; retrieval will pass an arbitrary content+provenance bundle
  with `Options.Budget` set. The budget path is implemented (extractive
  truncation) and tested now so P4 can call the same function.
- **No LLM**: none of canonicalize/chunk/distill import `internal/llm`
  (asserted by `TestPipeline_NoLLMDependency` via `go list -deps`); the
  abstractive hook ships interface-only with a no-op default.
