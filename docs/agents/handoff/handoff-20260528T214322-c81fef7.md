### Design decisions made

- **Types in `internal/schema`**: The natural home for `IntakeRecord` would be `internal/intake`, but `internal/store` needs that type, and `internal/intake/worker.go` imports `internal/store`, creating a cycle. Placing types in the already-existing schema package (which has no upstream intra-repo imports) breaks the cycle cleanly.
- **Governor callback pattern**: `Worker` accepts `recordAction func() error` instead of `*governor.Governor` to avoid pulling `internal/governor` (which imports `internal/navi/skill` → `internal/artifact` → `internal/store` → cycle). Callers pass `gov.RecordAction` as a bound method.
- **`EmitBytes` on Emitter**: The Telegram bot marshals the record itself (avoiding an `internal/intake` import in the plugin) and calls `intakeEmitFn(ctx, data)`. The emitter's `EmitBytes` method accepts the pre-marshaled payload.
- **Emission placement in `handleUpdate()`**: Emission fires after the `shouldProcessGroupMessage` guard (captures only real user content, not group-member-join events etc.) but before routing. Non-fatal: a failed emit is logged at Warn and normal message handling continues.
